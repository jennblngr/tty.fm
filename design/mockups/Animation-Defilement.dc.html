03 lecteur · artiste + album trop longs

// tient dans la largeur : texte fixe néons // nova kid · album « basse ville »
// trop long : défilement infini tard le soir
// mira sol & les échos · album « les nuits où l'on ne dort pas (édition deluxe) » // mira sol & les échos · album « les nuits où l'on ne dort pas (édition deluxe) »

≡ comportement

déclencheur seulement si « artiste · album » dépasse la largeur disponible ; sinon le texte reste fixe.
boucle      le texte est répété avec 48 px d'écart : quand la copie arrive au début, la boucle repart sans saut visible.
pause       le texte reste immobile au début de chaque boucle (15 % de la durée), pour pouvoir le lire.
bords       fondu sur 16 px à gauche et à droite, pour que le texte n'apparaisse pas coupé net.
où          lecteur mobile et desktop. le titre du morceau suit la même règle s'il dépasse aussi.

∿ paramètres

vitesseconstante, ≈ 40 px/s : la durée dépend de la longueur du texte. courbelinear répétitioninfinie, tant que l'écran est visible mouvement réduitpas de défilement : texte tronqué avec … accessibilitéla copie est masquée aux lecteurs d'écran (aria-hidden).

▤ implémentation

.marquee { overflow: hidden; mask-image: linear-gradient(90deg, transparent, #000 16px, #000 calc(100% - 16px), transparent); } .marquee-track { display: inline-flex; gap: 48px; white-space: nowrap; animation: marquee var(--duree) linear infinite; } /* --duree = (largeur texte + 48) / 40 px/s, + 15 % de pause */ @keyframes marquee { 0%, 15% { transform: translateX(0); } 100% { transform: translateX(calc(-50% - 24px)); } } @media (prefers-reduced-motion: reduce) { .marquee-track { animation: none; } .marquee-track > :last-child { display: none; } .marquee-track > :first-child { overflow: hidden; text-overflow: ellipsis; } } /* activer seulement si scrollWidth > clientWidth (recalculé au redimensionnement) */
