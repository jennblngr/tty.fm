≡ comportement

ouverture le panneau monte du bas de l'écran pendant que le fond s'assombrit (0 → 72 %). ça part vite et ça se pose en douceur.
fermeture le panneau redescend plus vite qu'il n'est monté, et le fond s'éclaircit en même temps.
fermer    tap sur le fond, tap sur une action, glisser le panneau vers le bas (au-delà de 30 % de sa hauteur ou vite), bouton retour.
glisser   pendant le geste, le panneau suit le doigt et l'opacité du fond baisse en proportion. relâché trop tôt, il revient en place.
desktop   pas de panneau : le menu déroulant apparaît en fondu + 4 px de glissement vers le bas, 120 ms.

∿ paramètres

ouverture320ms · cubic-bezier(0.32, 0.72, 0, 1) fermeture220ms · cubic-bezier(0.4, 0, 1, 1) propriétéstransform: translateY (panneau) · opacity (fond) mouvement réduitpas de glissement : panneau et fond apparaissent en fondu, 120 ms. accessibilitéfocus placé sur la première action, piégé dans le panneau, rendu au bouton [···] à la fermeture.

▤ implémentation

.sheet-backdrop { position: fixed; inset: 0; background: rgb(17 17 27); opacity: 0; pointer-events: none; transition: opacity 220ms cubic-bezier(0.4, 0, 1, 1); } .sheet { position: fixed; left: 0; right: 0; bottom: 0; transform: translateY(100%); transition: transform 220ms cubic-bezier(0.4, 0, 1, 1); } .open .sheet-backdrop { opacity: 0.72; pointer-events: auto; transition: opacity 320ms cubic-bezier(0.32, 0.72, 0, 1); } .open .sheet { transform: translateY(0); transition: transform 320ms cubic-bezier(0.32, 0.72, 0, 1); } /* pendant le glissé : transition: none, transform = translateY(dy px), opacité du fond = 0.72 × (1 − dy / hauteur) */ @media (prefers-reduced-motion: reduce) { .sheet, .open .sheet { transform: none; transition: opacity 120ms; } .sheet { opacity: 0; } .open .sheet { opacity: 1; } }
