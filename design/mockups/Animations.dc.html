02 barre latérale (desktop)

≡ comportement

barre   glisse de l'onglet quitté jusqu'à l'onglet choisi.
texte   la couleur verte traverse les lettres dans le sens du déplacement : elle sort de l'ancien onglet, passe sur ceux qu'on survole et entre dans le nouveau, en même temps que la barre.
sens    mobile : balayage horizontal. vers la droite, la couleur entre par la gauche ; vers la gauche, par la droite.
         desktop : balayage vertical, comme la barre. vers le bas, la couleur entre par le haut ; vers le haut, par le bas.
contenu la page change dès le clic ; seule l'animation du menu dure.

∿ paramètres

durée{{dur}} // réglable dans les tweaks de cette page courbecubic-bezier(0.65, 0, 0.35, 1) propriétésleft (barre) · background-position (texte) mouvement réduitsi prefers-reduced-motion : pas de glissement, simple changement de couleur en 120 ms.

▤ implémentation

// le texte porte un dégradé en 3 bandes (gris | vert | gris), 3 fois plus large que lui. on choisit la bande visible avec background-position.
.tab-label { color: transparent; background: linear-gradient(90deg, var(--muted) 33.33%, var(--accent) 33.33% 66.66%, var(--muted) 66.66%); background-size: 300% 100%; -webkit-background-clip: text; background-clip: text; transition: background-position 360ms cubic-bezier(0.65, 0, 0.35, 1); } .tab-label.before { background-position: 0% 0; } /* à gauche de l'onglet actif */ .tab-label.active { background-position: 50% 0; } /* onglet actif : bande verte */ .tab-label.after { background-position: 100% 0; } /* à droite de l'onglet actif */ .indicator { transition: left 360ms cubic-bezier(0.65, 0, 0.35, 1); } /* desktop : même principe, à la verticale */ .sidebar .tab-label { display: inline-block; background-image: linear-gradient(180deg, var(--muted) 33.33%, var(--accent) 33.33% 66.66%, var(--muted) 66.66%); background-size: 100% 300%; } .sidebar .tab-label.before { background-position: 0 0%; } .sidebar .tab-label.active { background-position: 0 50%; } .sidebar .tab-label.after { background-position: 0 100%; } .sidebar .indicator { transition: top 360ms cubic-bezier(0.65, 0, 0.35, 1); }
